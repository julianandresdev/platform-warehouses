################ batch

== Reporte diario: batch -> S3 -> Lambda -> central ==
En AWS (con la EC2 desplegada, ver docs/aws.md), el batch corre contra las APIs públicas y el bucket real;
la Lambda se dispara sola al crearse reports/daily/<fecha>/summary.json:
  PYTHONPATH=services/batch:services/common WH001_API_URL=http://$HOST:8101 WH002_API_URL=http://$HOST:8102 \
  WH003_API_URL=http://$HOST:8103 API_KEY=... CENTRAL_API_URL=http://$HOST:8004 CENTRAL_API_KEY=... \
  S3_BUCKET=<bucket> python -m batch.daily_report --date $(date -u +%F)

Local, con MinIO (la Lambda no corre en local: se prueba con un evento S3 de ejemplo):
